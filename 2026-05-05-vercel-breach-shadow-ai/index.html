サプライチェーン攻撃の3条件を、拡張機能はすべて満たしている

Vercel（Webホスティング大手）が4月、社員が業務で使っていたChrome拡張機能「Context.ai」経由で侵害された。

この事件はサプライチェーン攻撃そのものだ。サプライチェーン攻撃とは、攻撃者が標的を直接攻めず、標的が依存している外部のソフトウェアを侵害することで、間接的に標的に到達する手口を指す。

サプライチェーン攻撃の典型的な3条件はこうだ：

  1. 第三者のコードが、自分のシステムで実行されている
  2. そのコードを暗黙のうちに信頼している
  3. 第三者が侵害されたとき、自分は何もしていないのに被害者になる

Vercelの事件は3つすべてを満たしている。Context.aiという拡張機能のコード（第三者）が社員のブラウザで動き（自分のシステム）、Googleドライブへの広い権限を渡されており（暗黙の信頼）、Context.aiのサーバーが侵害された結果（第三者の侵害）、Vercelの環境変数が窃取された（自分は何もしていないのに被害者）。

この構造は、npmパッケージのサプライチェーン攻撃と完全に同じだ。違うのは「攻撃の入口がブラウザだった」ことだけ。

サイレント更新が攻撃を成立させる

ブラウザ拡張機能には、npmパッケージにはあまり意識されない特殊なリスクがある。自動更新だ。

拡張機能は提供元が新バージョンを公開すると、ユーザーの同意なしに静かに更新される。インストール時には善良なコードでも、数ヶ月後のアップデートでマルウェアが混入していることがある。

実際に繰り返し起きているパターンがある：

  • 開発者が拡張機能の権利を売却する
  • 新しいオーナーがアップデートで悪意あるコードを混入させる
  • ユーザーは何も気づかずに更新を受け取る

開発者の侵害が起点になることもある（今回のContext.aiのように、社員のデバイスがマルウェアに感染してアクセストークンが漏れたケース）。

ブラウザ拡張機能の自動更新メカニズムは、攻撃者にとって理想的な配信チャネルになっている。一度ストアに通れば、何百万のブラウザに静かに毒を撒ける。

ホワイトリストと評判ベースの審査では足りない

これに対して企業の取っているアプローチは、拡張機能のインストール制限・許可リスト管理・ストアの評判ベースの判断が中心だ。

しかしどれも今回のような攻撃には効かない。

  • ホワイトリスト: Context.aiは「正規の拡張機能」だった。リストに乗っていても問題なかった
  • 評判: インストール数も評判もそれなり。それでも侵害された
  • 権限審査: 「Googleドライブへのアクセス」は機能上正当だった。妥当だから許可される

これらは「インストール時点」の判断に依存している。しかしサプライチェーン攻撃は、インストール後に拡張機能が変質することで成立する。インストール時の審査がいくら完璧でも、後日の自動更新でマルウェアが混入されれば防げない。

npm パッケージと同じ扱いをすべきだ

Aikido Securityの指摘は、結論として明快だ。ブラウザ拡張機能は、npmパッケージと同じセキュリティアプローチで管理されるべき。

開発組織は npm パッケージに対して、すでに以下の対策を取っている：

  • 依存ツリー全体をスキャン（Software Composition Analysis）
  • 既知の脆弱性をデータベースと照合（CVEチェック）
  • 新バージョン公開時の継続的な監視
  • 信頼できないメンテナの動きを追跡

ブラウザ拡張機能には、これらの仕組みがほとんどない。Chromeウェブストアの審査は緩く、アップデート時の再審査は限定的で、第三者の継続的な監視ツールも未成熟だ。

しかし拡張機能は実質的にコード依存だ。ブラウザ内でフルアクセスを持つ第三者コードを実行している。それは「業務PCで動く npm パッケージ」と何も変わらない。

自分たちの組織は何をすべきか

Vercel侵害は、ブラウザ拡張機能をサプライチェーンの一部として認識し直すよう促している。具体的には：

  • 業務PCの拡張機能を棚卸しする。何が入っているか、誰が入れたか、なぜ必要かを把握する
  • 拡張機能をChrome Enterpriseなどで企業ポリシー管理し、無断インストールを防ぐ
  • 既知のセキュリティインシデント情報を継続的に監視する（npmで npm audit を回すのと同じ感覚で）
  • 「便利なAIツールを試したい」という社員のニーズに対し、会社として承認プロセスを用意する

Vercelは「ずさんな社員のせいで侵害された会社」ではない。npmパッケージへの依存と同じ警戒を拡張機能にかけていなかった、現代のすべての組織を代表する事例だ。

ブラウザ拡張機能はもはや、ブラウザの便利機能ではない。**業務システムの一部であり、サプライチェーンの一部だ。**そう扱わない限り、同じ事件は形を変えて繰り返される。
