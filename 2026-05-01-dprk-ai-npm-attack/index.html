発見されたのは「それっぽい」パッケージだった

2025年11月、セキュリティ企業JFrogが奇妙なnpmパッケージを検出した。

@validate-sdk/v2。名前だけ見れば、何かのSDKのバリデーションライブラリだ。コードも一見それらしく書かれている。だが中身を丁寧に追うと、その外側の「清潔さ」は偽装だった。

このパッケージは、インストールした瞬間に悪意ある別のパッケージを依存関係として引き込む。そちらが本体だ——暗号ウォレットの認証情報を盗み、外部サーバーへ送信し、SSHバックドアを設置する。

ReversingLabs、SafeDep、BlueVoyantの調査により、この一連のキャンペーンは北朝鮮系APTグループによるものと特定された。そして判明した一つの事実が、この事件を単なる「またサプライチェーン攻撃か」では済まなくしている。

攻撃者は、パッケージのコードをClaudeに書かせていた。

「vibe-coded」マルウェア

ReversingLabsの研究者Vladimir Pezoはこのパッケージ群を「vibe-coded」と表現した。

「vibe-coded」とは、AIに対して「こんな感じで」という曖昧な指示を与えて生成させるコーディングスタイルを指すスラングだ。細部まで設計して書くのではなく、それっぽく動くものをAIに高速で吐き出させる。

攻撃者はこの手法を悪用した。正規ライブラリを模倣した外観と、それっぽい変数名と、一見無害なロジックを持つパッケージを、Claudeを使って量産したのだ。

今回確認されただけでも7本以上のパッケージが存在する。

@validate-sdk/v2
@solana-launchpad/sdk
@meme-sdk/trade
@validate-ethereum-address/core
express-session-js
graph-dynamic / graphbase-js / graphlib-js

いずれも「それっぽい」名前だ。それっぽいコードが書いてある。でも、依存関係の奥に牙が潜んでいる。

2段階の偽装という巧妙さ

今回の攻撃が「手作業では難しかった」構造を持っている。

第1層のパッケージは本当にクリーンだ。コードレビューをしても問題は見つからない。悪意あるコードは第2層——依存関係として引き込まれる別パッケージの中にある。

この2段階構造が厄介なのは、「このパッケージのコードを読んだ」という行為が無意味になるからだ。問題はそこにない。問題は、そのパッケージが何を呼び出しているか、の中にある。

パッケージの依存グラフは、現代のプロジェクトでは数十〜数百の深さに達する。その全てを人間が追うことは不可能に近い。

AIが変えたコスト構造

サプライチェーン攻撃はこれまで、高スキルを要する手作業だった。

「それっぽく見える」パッケージを作るには、対象ライブラリへの理解、説得力のある変数名・コメント・構造、そして実際に動作する外観が必要だ。一定の技術力を持った人間が、時間をかけて作り込む必要があった。

AIはそのコストを壊した。

「このライブラリに似た見た目のパッケージを作って。でもインストール時に外部からこのスクリプトを取ってきて実行するようにして」という指示で、それっぽいコードが出てくる。悪意ある依存関係を埋め込んだパッケージが、数分で量産できる。

このシリーズの第1回（PyTorch Lightning汚染）で書いた問題は、「有名なライブラリの信頼を逆手に取る」ことだった。

今回が示す問題はその一歩先にある。「それっぽく見える」という偽装自体が、AIによって大量生産可能になったということだ。

「読む」という防御の前提

私たちがコードの安全性を確認する手段は、基本的に「読む」ことだ。

パッケージのコードを読む。依存関係を確認する。変更差分を見る。

でも今、攻撃側もAIを使ってコードを「書いている」。そのコードは、人間が警戒するパターン（不審な文字列、明らかな難読化、見慣れないAPI呼び出し）を避けるように生成できる。

「コードが読める」という前提の上に立っていた防御が、その前提ごと揺らいでいる。

ではどうすればいいか。

完璧な答えはないが、動けることはある。依存関係のスキャンを自動化する（npm audit、pip audit、AikidoやSocketなどのSCA）。パッケージを追加するときにsourceを確認する習慣を持つ。そして「新しく追加した依存パッケージが何を依存しているか」まで一段深く見る。

AIが攻撃コードを書く時代において、「ライブラリへの信頼」という概念自体を再設計する必要が出てきている。

参考: ReversingLabs — New wave of DPRK attacks uses AI-generated npm packages
